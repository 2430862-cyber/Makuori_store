\# PRD: Product Requirements Document



\## 1. Project Overview

\*\*Project Name:\*\* Makuori Store



Makuori Store is an online store for handmade macramé products and hijabs. It allows customers to browse products and place orders online.



\## 2. Objectives

\- Display products with images, prices, and descriptions.

\- Allow customers to register, log in, and place orders.

\- Allow administrators to manage products and orders.

\- Provide a simple and user-friendly shopping experience.



\## 3. User Roles

\- \*\*Customer:\*\* Browse products and place orders.

\- \*\*Admin:\*\* Manage products and customer orders.

\- \*\*Staff:\*\* View and update order status.



\## 4. Functional Requirements

\- User registration and login.

\- Product listing and product details.

\- Product management by administrators.

\- Order placement by customers.

\- Order status management by authorized staff.

\- Role-based access control.



\## 5. Non-Functional Requirements

\- The system should be easy to use.

\- Passwords must be stored securely.

\- Only authorized users can access protected features.

\- The application should respond to requests efficiently.

\## 6. Technology Stack

\- Frontend: React.js with TypeScript

\- Backend: FastAPI with Python

\- Communication: REST API

\- Version Control: Git and GitHub



\## 7. Scope

The project covers product browsing, user authentication, product management, and order management. Online payment integration is outside the initial scope.



\## 8. Success Criteria

The project is successful when users can log in, browse products, place orders, and access features according to their assigned roles.
